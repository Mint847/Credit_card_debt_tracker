# Design

Early design material for Serendib. None of it is used by the app; it's kept as a record of how the design started.

| Folder | What's inside |
|---|---|
| `mockups/` | The original screen mock-ups (home, card overview, simulators, spaces, offers, sign-in and more). Each folder has the mock-up's `code.html`, a `screen.png` and its `DESIGN.md` notes. `stitch-concepts/` holds the first card-list and payoff-simulator concepts and the "Serendib Neo Fintech" design brief |
| `archives/` | The same mock-ups as the zip files they were exported in |
| `inspiration/` | Reference sites and design notes |

The app itself lives in [`apps/desktop`](../apps/desktop) and the shared logic in [`packages/core`](../packages/core).
